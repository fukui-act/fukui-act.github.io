Why we paused the website

  1. On October 20, 2026, the developers of PHP, a programming language widely used to run websites, announced in advance that they would release fixes for two serious security vulnerabilities. Both are rated in the highest category (Critical, CVSS 9.2). Advance notices like this are rare.
  2. The fixes are scheduled for release at 11:00 p.m. on Wednesday, October 21, 2026 (Japan time). Which versions are affected, and the details of the flaws, are to be announced at the same time.
  3. This website is a static site served by GitHub Pages, and the pages themselves do not use PHP. However, they load external services for fonts, the venue map, and visitor statistics.
  4. As a precaution, we have paused the website until the details are known and we have confirmed that these services are not affected. While it is paused, this notice page loads no external services at all.
  5. The website was not paused because of unauthorized access or any other damage.

When we expect to reopen

We plan to confirm there is no impact on the morning of Thursday, October 22, 2026, and then restore the original pages.
